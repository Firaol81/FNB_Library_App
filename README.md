# FNB Library 📚🎶

FNB Library is a fully responsive frontend web application that allows users to read a curated collection of books online — including romantic stories, children’s books, and traditional folktales.

## ✨ Key Features
- Responsive and mobile-friendly design built with HTML, CSS, and JavaScript
- Original romantic and cultural stories with smooth navigation
- Custom-designed book covers and visuals created using **Canva**
- Integrated music player allowing users to listen while reading
- Fully frontend project — backend features (accounts, uploads) coming soon

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript
- Canva (for visual design)

## 📌 Project Status
Frontend completed. Backend functionality (like login, upload, and user features) planned for future release.
